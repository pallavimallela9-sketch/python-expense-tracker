# Expense Tracker

This Python program is an expense tracking application that allows users to record, view, search, delete, and analyze their daily expenses.

## Features

* Add new expenses
* Store date, category, description, and amount
* View all recorded expenses
* Calculate total expenses
* Search expenses by category
* Calculate category-wise expenses
* Delete an existing expense
* Display an expense summary
* Menu-driven interface

## Technology Used

* Python

## Concepts Used

* Lists
* Dictionaries
* Loops
* Conditional statements
* Exception handling
* String methods
* `enumerate()`
* `sum()`
* User input
* Menu-driven programming
